   - Voice AI quickstart (Agents): https://docs.livekit.io/agents/start/voice-ai/
   - Agents GitHub repo: https://github.com/livekit/agents

Suggested research focus for each:
- Review the Flutter SDK API for connecting to rooms, subscribing to tracks, and monitoring audio levels.
- Check the Flutter quickstart and example app for implementation patterns.
- Examine the components-flutter repo for ready-made UI widgets.
- Read the Agents frontend integration docs for how state events and TTS/STT streams tie into the LiveKit pipeline.
- Review the Voice AI quickstart and Agents GitHub to understand the server-side behavior that emits status events.
