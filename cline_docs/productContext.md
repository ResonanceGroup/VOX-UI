# VOX-UI Product Context

## Project Purpose
VOX-UI is a sophisticated AI Assistant interface featuring an animated, interactive orb that serves as the visual centerpiece for AI interactions. The project creates an immersive, modern UI experience for AI assistants with real-time visual feedback.

## Problems It Solves
- **Visual Feedback**: Provides clear, animated visual indicators for different AI states (idle, processing, executing, notifying, etc.)
- **User Experience**: Creates an engaging, modern interface that makes AI interactions feel more natural and responsive
- **State Communication**: Uses visual cues (colors, animations, particles) to communicate AI status without requiring text-heavy interfaces
- **Audio Integration**: Includes audio level visualization that responds to voice input intensity

## How It Should Work
The interface centers around a glass-like orb that:
- **Displays different states** through color changes, animations, and effects
- **Responds to audio input** with intensity-based visual feedback
- **Shows processing states** with animated ellipsis and visual effects
- **Provides notifications** through particle burst effects
- **Maintains smooth transitions** between all states

## Key Features
- Animated glass orb with swirling internal elements
- Multiple AI states: idle, executing, processing, notifying, muted, disconnected
- Audio level visualization with real-time intensity mapping
- Particle effects for notifications
- Smooth state transitions with visual feedback
- Dark/light theme support
- Mobile-responsive design with touch optimization

## Target Use Case
This appears to be designed as a voice-first AI assistant interface, where the orb provides visual feedback during voice interactions, processing, and notifications.
